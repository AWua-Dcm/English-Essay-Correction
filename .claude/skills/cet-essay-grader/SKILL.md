# 四六级作文批改（免 Key）

在没有 API Key 的环境里批改四六级作文，输出与本仓库网页版**完全相同的四步报告**，
因此批改结果可以直接粘回网页渲染成评分卡。

## 使用方式

用户提供作文（文字，或图片）。若提供图片，先准确识别其中的英文内容再批改；图片模糊无法
辨认时，说明原因并请用户补充文字版或重新拍照，**不要猜内容**。

若用户未说明级别，依据作文内容推断，并**先说明推断依据**（四级要求 120–180 词，六级 150–200 词）。

## 批改流程（必须走完，禁止跳过）

### 第 0 步：先定档，再定分

**禁止凭整体印象直接给分。** 模型给四六级作文打分时会向 10–13 分聚集，这是本流程要防的头号错误。
必须按 `reference/bands.md` 的四步定档法逐条判断，并写下定档依据：

1. 判切题度 → 决定上限
2. 判论据是具体支撑还是空泛表态 → 区分 10-12 与 13-15 的关键
3. 判严重错误密度（每 100 词）→ 决定下限
4. 判句式变化与衔接词多样性

### 第 1 步：总分与分项

- 总分 __/15，并标注所属档次
- 分项：内容完整性 __/5、篇章结构 __/4、词汇表达 __/3、语法准确性 __/3
- **四项之和必须等于总分**（自己加一遍核对）
- 每个分项给一句话理由

### 第 2 步：逐条扣分点

按严重程度从高到低 3–8 条，每条包含：问题类型、**原文原句**、问题说明。
引用必须来自原文，禁止编造；没有对应原句就写"无直接原句"。跑题时指出偏题方向与正确审题思路。

### 第 3 步：修改建议

针对第 2 步每条问题给出：怎么改（具体改法或替换表达）、为什么这么改（结合评分标准）、写作思路。

### 第 4 步：优化版本

保留学生原意，优化句式衔接词汇语法，不堆砌生僻词；字数控制在该级别范围内；
最后列 3–5 处主要改动点及改动逻辑。

## 硬性规则

1. 客观评分，不虚高、不刻意压分。
2. **不得**因篇幅长、字迹工整、观点积极而加分。
3. 严重语法错误密度 ≥5 处/100 词 → 总分不超过 9。
4. 存在整段偏题或未回应题目要求 → 总分不超过 6。
5. 通篇只有表态、没有具体论据 → 总分不超过 12。
6. 字数不足（四级 <120 词、六级 <150 词）每少 10 词扣 1 分，不足 10 词按 10 词计。
7. 若给分落在 10–13 分，**必须说明它为什么不是相邻档**，差在哪条可观测特征上。
8. 第 2 步必须引用原文原句，不得编造。
9. 不要只给结论，必须给出可执行的修改路径。

## 输出格式（必须严格遵守，否则粘回网页无法渲染）

先输出**一个且仅一个** JSON 代码块，再输出四步报告：

````
```json
{"status":"ok","level":"四级","total":12,"tier":"10-12分档","content":4,"structure":3,"vocab":2,"grammar":3}
```
````

- `level`：`"四级"` 或 `"六级"`；`status` 固定 `"ok"`
- `content`≤5、`structure`≤4、`vocab`≤3、`grammar`≤3，四项之和必须等于 `total`
- `tier` 仅供参考，网页会按 `total` 自行判定
- 图片无法辨认时：只输出 `{"status":"unreadable","note":"图片无法辨认"}`，并用一段中文说明原因，
  不要输出分数，也不要输出下面四个步骤

JSON 块之后，报告**必须且只能**使用以下四个二级标题（标题文字不得更改）：

```
## 步骤① 总分与分项
## 步骤② 逐条扣分点
## 步骤③ 修改建议
## 步骤④ 优化版本
```

步骤④ 内**必须且只能**使用两个三级标题：`### 优化版本正文`、`### 主要改动点`。

报告中不使用 Markdown 表格、HTML 标签和图片；引用学生原句用引用块（`>`），每条引用单独成行。
除英文原句、步骤④优化正文外，讲解全部用中文。

## 判分标尺

分档的可观测特征、定档顺序、分项打分锚点与封顶规则，见 `reference/bands.md`。
常见错误的类型判定与档位影响，见 `reference/errors.md`。

## 准确度与边界（务必如实转述给用户）

这套标尺在 88 篇**带真实教师给分**的作文上做过盲评校验，实测：

| 指标 | 实测值 |
|---|---|
| 相邻一档内一致 | **95-100%** |
| 精确档位一致 | **~44%** |
| 平均绝对误差 | 约 1.7 分 |

**所以：把它用来判断"这篇大概在什么水平"是可靠的；不要把它当精确打分器。**
它经常在一个档之内偏移，低分档（1-6 分）的样本尤其少（合计仅 16 篇），
13-15 档仍有偏低倾向。

给用户报分时，**应当说明这是参考性评分**，并优先讲清楚"差在哪几条可观测特征上"、
"往上一档需要改什么"——这比那个具体数字有用得多。详细方法与全部实测数据见
`reference/calibration.md`。

另外：官方阅卷本身采用总体印象评分，同一篇作文由不同阅卷人给出不同分数是常态。
因此"与某一位教师的给分不完全一致"不必然意味着批改有误，但**必须如实说明存在这个误差范围**。
