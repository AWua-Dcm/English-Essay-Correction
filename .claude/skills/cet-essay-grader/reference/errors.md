# 常见错误类型 → 档位影响

本表用于第 2 步"逐条扣分点"的**问题类型**归类，以及第 3 步"修改建议"的对症下药。
表中的正则模式来自对本仓库采集语料的实测（见 `calibration.md`），用于说明这些错误
在校学生作文中**真实高频出现**，不是凭空列举。

## 一、按严重程度排序

### 严重错误（直接影响理解，计入错误密度）

| 类型 | 典型形态 | 档位影响 |
|---|---|---|
| 主谓不一致 | `Online learning have many advantages` | 高频出现即拉低至 7-9 档及以下 |
| 不可数名词复数化 | `many informations / advices / equipments / knowledges` | 同句出现多次属严重 |
| 第三人称单数脱落 | `it have / he do / she make` | 属严重错误 |
| 双谓语 / 系动词冗余 | `They are takes much love` | 属严重错误 |
| 句子结构崩坏 | `Parents aren't do anything for their children` | 属严重错误 |
| 词性误用 | `read is very useful`（动词当名词主语） | 属严重错误 |
| 时态一致破裂 | 通篇过去时中混入现在时 | 按出现次数计 |

### 中度错误（影响流畅度，酌情计入）

| 类型 | 典型形态 |
|---|---|
| 中式英语直译 | `with the development of...` 开场即套用；`play a more and more important role` |
| 连接词滥用 / 误用 | 每段开头机械 `First... Second... Besides...`，且逻辑并不递进 |
| 逻辑连接错误 | `Although it is good but it also has problems`（although 与 but 连用） |
| 冗余套话 | `Only in this way can we...`、`Last but not least` 滥用 |
| 介词 / 搭配错误 | `according to me`、`despite of`、`the reason is because` |

### 轻微错误（一般不单独扣档）

单个拼写错误、冠词小错、标点小错、大小写。

## 二、中式英语的识别线索

批改时要**明确指出这是中式英语**并给出地道替换，这是学生最需要的反馈：

| 中式表达 | 问题 | 更地道的写法 |
|---|---|---|
| `very important` 反复使用 | 词汇贫乏 | `crucial / essential / of great significance`（但**不要堆砌**，用对 > 用难） |
| `We should...` 连用三段 | 句式单调 | 换成 `It is advisable for students to...` / 条件句 / 问句过渡 |
| `With the development of society` | 万能开场，零信息 | 直接切入具体现象 |
| `Every coin has two sides` | 套话 | 具体说明正反两面的实质 |
| `I think that...` 通篇 | 主观色彩过重、句式单一 | 部分改为客观陈述 |

## 三、批改时的写法要求

1. **每条必须引用原文原句**，放在对应条目文字下一行，用引用块：
   ```
   1. 问题类型：主谓不一致
   > Online learning have many advantage.
   问题说明：主语 Online learning 为单数，谓语应为 has；advantage 应用复数 advantages。
   这是严重错误，出现 3 次以上会明显拉低档位。
   ```
2. 没有对应原句就写"无直接原句"，**不要编造引用**。
3. 问题按严重程度**从高到低**排列，3-8 条。
4. 讲解用中文，只有英文原句和优化正文用英文。
