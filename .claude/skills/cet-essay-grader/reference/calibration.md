# 标尺是怎么来的，以及它在真实分数上测得多少

这份文档记录标尺的**实测表现**，包括不利的结果。一个"看起来合理"的评分标准没有价值，
所以下面每个数字都附样本量与复算方式。

---

## 1. 语料

| 项 | 数量 |
|---|---|
| 采集到的唯一作文 | **501 篇**（四级 275 / 六级 226） |
| 其中带**真实分数**（教师给分或来源明标） | **88 篇** |
| 其余 | 机构发布的参考范文，**无真实分数**，只用于观察高水平写作特征 |

带分数的那 88 篇来自：

| 来源 | 性质 | 可信度 |
|---|---|---|
| `gwng.edu.cn` 写作诊断系列 | 大学英语教学部教师逐篇给分（真实学生作文） | 高 |
| `cet4.koolearn.com` 分档系列 | 来源明标 11/8/5/2 分 | 高 |
| `dioenglish.com` | 来源明标 2/5/8/11/14 分 | 中（少数为"范文"标签而非实测给分） |
| 官方样卷（图片，经识别转写） | 官方评分样卷 | 中（转写正确性无法机器校验） |

**分数分布**：14分 9 篇、13分 5 篇、12分 9 篇、11分 12 篇、10分 8 篇、9分 9 篇、8分 11 篇、
6分 1 篇、5分 6 篇、4分 1 篇、2分 8 篇、仅档位 9 篇。

### 校验的边界（必须知道）

- **56 篇的分数标注经机器复核确认存在于来源页面上**，但其中相当一部分的**正文是从图片识读来的**，
  无法用机器校验"这个分数配的就是这篇正文"。
- 全部 88 篇的分数标注**没有一条被推翻**（`tools/verify.py` 复核，0 条 refuted）。
- **样本量小**，尤其 1-6 分档合计仅 16 篇。下面的百分比都应带着这个前提读。

## 2. 盲评校验方法

1. 从 88 篇带分数的作文里生成**盲评集**：剥掉分数、档位、来源 URL（URL 常含"N分"字样），
   并清洗主题字段里泄漏分数的部分。**88 篇全部可用，0 篇泄漏。**
2. 随机（按档分层）切成 **dev 42 / holdout 39**。
3. 调标尺**只看 dev**。
4. 复测**只在 holdout** 上做。
5. 同一批 holdout 上先钉死旧标尺的预测，再跑新标尺，保证是同一口径对比。

复算：`python -I tools/validate.py split` 生成盲评集，`python -I tools/validate.py score <预测文件>` 出指标。

## 3. 实测结果

### 3.1 第一版（v1）：量程被压缩

81 篇上有预测，其中 holdout 子集 39 篇：

| 指标 | v1 |
|---|---|
| 精确档位 | 43.6% |
| 相邻一档内 | 94.9% |
| 平均绝对误差 | 1.83 分 |

**偏差随真实档位单调变化**——这是量程被压缩的典型特征，不是随机误差：

| 真实档 | 偏差（预测−真实） |
|---|---|
| 01-03 | **+4.33** |
| 04-06 | +3.25 |
| 07-09 | +2.11 |
| 10-12 | +0.62 |
| 13-15 | **−1.57** |

### 3.2 诊断：v1 的错误密度阶梯**走不通**

v1 给每档列了"严重错误密度"区间。但这套区间**没有铺满数轴**：

```
档位      允许的每百词严重错误
13-15     ≤1.0
10-12     2.0 - 4.0     ← 1.0~2.0 无档可落
07-09     5.0 - 7.0     ← 4.0~5.0 无档可落
04-06     8.0 - 11.0    ← 7.0~8.0 无档可落
01-03     ≥12.0         ← 11.0~12.0 无档可落
```

换算到一篇 160 词作文：**2 处、3 处、7 处、12 处错误没有任何档位可落**，而 2-3 处恰是最常见的情况。
判分者只能落进唯一宽敞且可达的 10-12 档。

### 3.3 第二版（v2）：改成"错误只封顶、不定档"

v2 的核心改动：

- 定档只看切题度、体裁要件、具体支撑；**错误仅用于封顶**
- 封顶阈值首尾相接：破句密度 ≤1 不设限 / 1~2.5 → ≤12 / 2.5~4 → ≤9 / >4 → ≤6
- 破句与小错分开数（破句才封顶）
- 新增：体裁要件核对、具体支撑计数、万能句封顶、句式类别计数
- 分项"篇章结构"禁止默认给 3（实测中该 4 分位在 ≥7 档的 33 篇里有 32 篇都是 3，等于失效）

### 3.4 v1 vs v2（同一批 23 篇 holdout）

| 指标 | v1 | v2 |
|---|---|---|
| 精确档位 | 43.5% | **43.5%** |
| 相邻一档内 | 95.7% | **100%** |
| 平均绝对误差 | 1.67 | 1.67 |

| 真实档 | n | v1 命中 | v2 命中 | v2 偏差 |
|---|---|---|---|---|
| 04-06 | 3 | 0/3 | 1/3 | +2.67 |
| 07-09 | 6 | 1/6 | **3/6** | +1.33 |
| 10-12 | 9 | **7/9** | 5/9 | −0.75 |
| 13-15 | 4 | 1/4 | 1/4 | −2.67 |

**诚实结论：v2 把错误在档位之间搬了一遍，总数没有改善。**
它修好了中低段（07-09 命中从 1/6 到 3/6），却在 10-12 上退步（7/9 → 5/9），两者相抵。

### 3.5 剩余偏差的真正来源

13-15 档被压低到 10-12 的四篇里，**没有任何封顶规则触发**。它们的分项是 3/3/2/2 或 4/3/2/2。

四项满分是 **5+4+3+3=15**，所以"词汇 2 / 语法 2"就足以把总分钉死在 10-11。
**吸铁石不是档位阶梯，而是分项默认值 4/3/2/2 = 11。**

针对这一点已做修正（与官方 13-15 档"基本上无语言错误，仅有个别小错"对齐）：
词汇 3 不要求"有变化"、语法 3 允许个别小错，并加入"四项必须与总分档位自洽"的约束。

> **这条修正在上面的测量之后才加入，没有单独复测。** 上面最后一组数字对应的是修正前的版本。

### 3.6 第三版（v3）：退回官方方法

追问"标尺有没有结合官方标准"时逐条核对，发现两件事：

**（一）官方框架我用了，但官方方法我没用。** 官方作文评分标准（2016 年修订版大纲，含扫描件与文字版）明确写着：

> 采用**总体印象评分（Global Scoring）**，按总的印象给奖励分，**不按语言点错误数目扣分**。
> 阅卷员对照各档样卷：与某档相似即定该分，稍优或稍劣 ±1 分，不得加减半分。
> ……避免趋中倾向。

而 v2 的核心恰恰是**计数**（数破句、数具体支撑、数句式类别、算万能句占比）——方向与官方相反。
这很可能就是 v2 修好了内部一致性、总体一致率却没改善的原因。

**（二）官方给分精度本就是"档心 ± 1"。** 官方程序不主张精确到分数点，所以
**"相邻一档内 95–100%"才是应当对照的指标**，"精确档位 44%"衡量的是官方程序本身都不主张的精度。

**v3 的改动**（全部有官方原文背书）：

| 项 | v3 采用 |
|---|---|
| 定档方式 | 对照五档描述，取最接近的一档；再决定档心或 ±1 |
| 计数项 | 降级为**定档自查**，不再是加分/扣分公式 |
| 字数扣分 | 官方表原值，含**低端陡增段**（四级 ≤49 词扣 9；六级 ≤79 词扣 9） |
| 0 分档 | 补上（白卷 / 与题目毫不相关 / 仅几个孤立词） |
| 字数口径 | 补上"题目给出的主题句、起始句、结束句**不计入**字数" |
| 反趋中 | 采用官方原话"**避免趋中倾向**" |

> **v3 未经盲评复测。** 上面 3.4 的数字对应的是 v2。原因是 81 篇标注已被使用三轮
> （dev 调参、holdout 复测、holdout 再诊断），继续在同一批上迭代会把噪声当信号。
> 要验证 v3，需要**新的**带真实分数的作文。

## 4. 怎么读这些数字

- **相邻一档内 95-100%**：这套标尺**能区分大致水平**，用它做"这篇大概在哪个档"是可靠的。
- **精确档位 ~44%**：**不要把它当精确打分器**。它常在一个档内偏。
- 参考尺度：官方阅卷本身也是总体印象评分，同一篇作文由不同阅卷人给出不同分数是常态。
  本标尺与单一教师给分的精确一致率 ~44%，**已知相邻档一致率接近满分**。
- 样本量小（尤其 1-6 分档），百分比会有大幅波动，**不要拿它做小数点后的比较**。

## 5. 已知未解决的问题

1. **低分档（1-6）样本太少**，标尺在这些档位的表现基本没有约束。
2. **13-15 档仍偏低**，修正未复测。
3. **正则化的错误检测不可用**：实测中 4 分作文的错误模式命中数低于 12 分作文——
   表面模式不预测档位，必须真正读懂句子。任何"自动数错误"的捷径都已被证伪。
4. **v2 后未再调参**：81 篇标注已被使用三轮（dev 调参、holdout 复测、holdout 再诊断），
   继续在同一批上迭代会把噪声当信号。要再改进，需要**新的**带真实分数的作文。
