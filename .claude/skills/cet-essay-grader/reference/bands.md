# 档位标尺（v3：官方五档对照法）

四六级作文满分 15 分。**本标尺以官方评分办法为准**，不自行发明判分公式。

> **为什么是 v3。** v1 用"错误密度区间"定档，但那套区间**没有铺满数轴**——一篇 160 词作文里
> 2、3、7、12 处错误**没有任何档位可落**，判分者只能挤进唯一宽敞的 10-12 档，造成低分被抬高。
> v2 改成计数封顶修好了连续性，但实测**总体一致率没有改善**（精确档位 43.5% → 43.5%），
> 而且方向上**与官方方法抵触**：官方明写"总体印象评分……**不按语言点错误数目扣分**"。
> 所以 v3 回到官方：以**档位描述对照**定档，计数只作自查。

## 一、官方评分办法

- 四六级写作采用**总体印象评分（Global Scoring）**，按总的印象给奖励分，**不按语言点错误数目扣分**
- 阅卷员对照各档样卷：**与某档相似即定该分，稍优或稍劣 ±1 分，不得加减半分**
- 从内容与语言两方面综合评判，**避免趋中倾向**
- 满分 15 分（写作占全卷 15%，710 分制下约 106.5 分）

**操作含义**：先判断"这篇最像哪一档"，再决定落在**档心**还是 **±1**。
官方精度本身就是"档心 ± 1"，所以不要把某个精确分数当成唯一正确答案。

## 二、五档描述（逐条对照，取最接近的一档）

| 档 | 描述（官方原文） |
|---|---|
| **14分档（13-15）** | 切题。表达思想清楚，文字通顺、连贯，基本上无语言错误，仅有个别小错。 |
| **11分档（10-12）** | 切题。表达思想清楚，文字连贯，但有少量语言错误。 |
| **8分档（7-9）** | 基本切题。有些地方表达思想不够清楚，文字勉强连贯；语言错误相当多，其中有一些是严重错误。 |
| **5分档（4-6）** | 基本切题。表达思想不清楚，连贯性差。有较多的严重语言错误。 |
| **2分档（1-3）** | 条理不清，思路紊乱，语言支离破碎或大部分句子均有错误，且多数为严重错误。 |
| **0 分** | 白卷，作文与题目毫不相关，或只有几个孤立的词而无法表达思想。 |

## 三、定档自查项（用于确认，**不用于算分**）

下面几项帮你确认"有没有看漏"，**不是加分扣分公式**。定档仍以第二节的描述为准。

| 自查项 | 看什么 |
|---|---|
| 切题度 | 是否回应了题目**全部**要求（见下表） |
| 具体支撑 | 有几处例子、数字、具体的人或物、两步因果链；是否通篇只有表态 |
| 破句 | 有几处句子**必须重写才能读懂**（缺谓语、双谓语、从句没有主句、整句不成句） |
| 句式类别 | 从句 / 非谓语 / 倒装 / 强调句，各有几类 |
| 万能句 | 把主题词换成本题以外的主题后，句子是否依然成立 |

**自查怎么用**：若你按描述定到 11 分档，却发现通篇只有表态、或大半句子不成句，
说明定档偏高——回到第二节重新对照。这就是自查的**全部**用途。

### 各体裁的"题目要求"

| 体裁 | 要件 |
|---|---|
| 图表作文 | 读出图中各时间点数值并说明趋势 |
| 图画作文 | 描述画面 + 解释寓意 + 表态 |
| 书信 | 称呼 / 说明目的 / 具体建议 / 落款 |
| 谚语题 | 解释 + 举例 + 表态 |
| 议论文 | 立场 + 两个理由 + 一句回应对立观点 |

- 规定的内容未写全者，**按比例扣分**

## 五、分项打分锚点

四项之和**必须**等于总分。

| 分项 | 满分 | 锚点 |
|---|---|---|
| 内容完整性 | 5 | 切题且题目要求写全 5；切题但展开不足 3-4；部分偏题 1-2；跑题 0 |
| 篇章结构 | 4 | 三段清晰、过渡自然 4；结构完整但过渡生硬 3；结构混乱或缺段 1-2 |
| 词汇表达 | 3 | 达意准确、无明显重复或中式表达 3（官方 13-15 档只要求文字通顺，**不要求高级词**）；重复或中式表达明显 2；用词错误影响理解 1 |
| 语法准确性 | 3 | 基本上无语言错误、仅个别小错 3；少量语言错误 2；错误相当多且含严重错误 1 |

**四项必须与总分档位自洽**：定档 13-15 时词汇与语法应为 3；若给 2，说明该文其实不足 13-15，
应下调总分。同理定档 4-6 及以下时，词汇与语法不应高于 2。

> 这一条来自实测：13-15 档被压低到 10-12 的四篇里，**没有任何封顶规则触发**，
> 全部是被"词汇 2 / 语法 2"拖下去的——四项满分 5+4+3+3=15，词汇与语法各给 2 就把总分钉死在 10-11。

## 六、硬性规则

1. 客观评分，不虚高、不刻意压分，**避免趋中倾向**（官方原话）
2. 不得因篇幅长、字迹工整、观点积极而加分
3. 严禁默认给出 11-13 分。给分落在 10-13 时，**必须说明它为什么不是相邻档**，差在哪一条描述上

## 七、常见误判

- **把"用了高级词"当成高分**：官方 13-15 档只要求"文字通顺"，用对常用词优于用错生僻词
- **把"模板痕迹"当成结构好**：模板化开头结尾不改写，属于"文字连贯"里的减分项
- **把"字数多"当成内容充实**：凑字数的重复表述按"表达思想不够清楚"处理
- **把逗号连接两个完整句当成破句**：那是少量语言错误，不改变档位判断
