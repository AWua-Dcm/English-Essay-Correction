# 四六级作文 AI 批改台

> 上线地址：**https://awua-dcm.github.io/English-Essay-Correction/**

严格对照大学英语四六级作文官方评分标准，把一篇作文变成一份规范的四步批改报告：

**① 总分与分项打分 → ② 逐条扣分点（引用原文）→ ③ 修改建议 → ④ 优化版本（含 3-5 处改动点）**

评分卡可视化（总分 /15、官方档次、四项分项）、字数达标核验、图片作文识别、报告可导出 PDF / Markdown / 离线 HTML。

---

## 快速开始（三种用法）

1. **直接用线上版**：打开 <https://awua-dcm.github.io/English-Essay-Correction/>，粘贴作文，点「开始批改」（需已在设置里配好 Key）或「复制批改指令」（免 Key）。
2. **复制模式（推荐先试，免 Key 全程免费）**：粘贴作文 → 点「复制批改指令」→ 粘贴到任意免费 AI 对话（DeepSeek 网页版 / Kimi / 豆包 / 通义 / ChatGPT 免费版）→ 把 AI 的整段回复粘回本页 → 点「渲染报告」。
3. **自动模式（有 API Key）**：点顶部模式条进入设置，选择服务商、填入 Key，保存后粘贴作文点「开始批改」，页内流式出报告。

## 两种批改模式

| 模式 | 怎么用 | 成本 | 备注 |
|---|---|---|---|
| 复制模式（免 Key） | 复制指令到任意 AI 对话，结果粘回本页渲染 | **全程免费** | 图片作文请把照片直接发到 AI 对话里（推荐支持看图的 Kimi / 豆包 / 通义） |
| 自动模式（有 Key） | 页内一键批改，流式输出 | 按服务商计费（DeepSeek 一篇约几分钱） | 需要服务商 API Key，Key 只保存在你的浏览器本地 |

两种模式共用同一套批改规则与报告排版；报告都可导出、存入本地历史。

## 常见问题

| 你看到的提示 | 怎么办 |
|---|---|
| API Key 无效或无权限 | 检查 Key 是否复制完整；点设置里「测试连接」自检；或**改用复制模式** |
| 账户余额不足 | 到服务商控制台充值，或改用复制模式 |
| 请求过于频繁（限流） | 稍后重试 |
| 该模型不支持当前请求参数 | 已自动重试过一次；仍失败请更换模型名 |
| 无法连接服务商（网络受限或不允许浏览器直连） | 检查网络；或**改用复制模式**（万能路径） |
| 报「模型不存在」 | 服务商可能更新了模型名：到其官方文档复制最新模型名填入设置 |
| 暂不支持 HEIC 格式 | 在手机相册导出为 JPG，或直接改用复制模式把照片发到 AI 对话 |
| 输出被截断 | 报告过长触达模型上限：重试一次或换输出上限更大的模型 |
| 微信里复制/下载受限 | 点右上角 ⋯ → 在浏览器打开页面 |

**万能路径**：任何自动模式的问题，都可以退回「复制模式」完成批改。

## 隐私说明

- 本页**无任何数据上报、无统计埋点、无第三方请求**（除你主动选择的大模型 API 外）。

## 维护指南

- **改默认模型名**：编辑 `assets/js/providers.js` 中对应服务商的 `defaultModel`（各服务商模型名会不定期更新）。
- **新增服务商**：在 `providers.js` 的 `PROVIDERS` 数组加一项（OpenAI 兼容协议：`baseURL` + `defaultModel` + 上下文/输出上限 + 核验日期）。
- **自检连通性**：页面设置抽屉里点「测试连接」。
- 每个预设都标注了 `lastChecked`（核验日期），设置里可见；发现问题优先核对服务商官方文档。
